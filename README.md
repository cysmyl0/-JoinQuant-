# A 杀强势结构策略 · 策略说明书

JoinQuant（聚宽）平台上的 A 股短线策略：**急跌后的「强势结构」反转买入，次日到压力区止盈**。
本文档是策略的完整口径说明（每条规则对应代码里的哪个函数、哪个参数都写清楚了）。

## 一、这个仓库里有什么

| 路径 | 说明 |
|---|---|
| `jq_strong_structure.py` | 策略本体，直接整份粘到聚宽「策略研究 → 策略列表 → 新建」里即可回测 |
| `聚宽策略使用说明.md` | 完整说明书：参数表、买入/卖出规则、规则与代码对照表、已知偏差 |
| [`docs/index.html`](docs/index.html) | **策略流程图**（单文件、无外部依赖，双击就能看；GitHub Pages 也能直接托管） |
| `docs/a-kill-candidate.json` | 流程图的源文件（改图后用它重新生成 HTML） |
| `local_test/` | 本地假聚宽环境：`test_rules.py` 逐条验规则、`test_strategy_flow.py` 跑完整买卖流程 |

## 二、怎么看流程图

- 直接下载 `docs/index.html` 用浏览器打开；
- 或访问 GitHub Pages（在仓库 Settings → Pages 里把 Source 选成 `main` / `docs` 目录）；
- 图里左侧是从「扫全市场」到「空仓」的主链，右侧是每一道闸门的否决出口，底部 8 张卡片写的是每一步的定义与细节。

## 三、本地跑测试

需要 Python + numpy（聚宽里不需要，只有本地测试用）：

```bash
python local_test/test_rules.py          # 186 项：规则逐条验证
python local_test/test_strategy_flow.py  # 82 项：假聚宽环境跑完整买卖流程
```

两个脚本当前都是 **全部通过**。

## 四、回测设置要点

- **频率必须选「分钟」**：止盈要在盘中触发（到目标价就卖），日线频率下 `handle_data()` 一天只调一次，盘中止盈会整体失效。
- 撮合方式、初始资金随意；策略自己按「单票最多 25% 仓位、最多 5 只」分配。
- 买入与放量减仓固定在 14:55（要用到当日到 14:55 为止的分钟成交量），止损、止盈、尾巴处理见说明书「卖出优先级」。
